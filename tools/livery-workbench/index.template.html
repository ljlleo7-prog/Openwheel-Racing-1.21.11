From picture to starting grid.

  1. Click a panel on the car, then Add picture or paste an image with Ctrl/Cmd+V. It fits the selected panel.
  2. Use Move to drag pictures and shapes. Drag the square handle to resize. Set precise position, size, rotation, and opacity below.
  3. Draw with the brush, lines, rectangles, or ovals. The eraser removes pixels from a selected image; brush strokes and shapes can be deleted as layers.
  4. Switch between Picture and Legacy to compare the same atlas. Original preset checks the untextured car.
  5. Export PNG creates a 512×512 file named picture_v1_…. In the mod, choose Import atlas in the livery editor, then Save.
  6. Save project keeps editable layers. The PNG is flattened. Everything stays in your browser; this page makes no network requests.
